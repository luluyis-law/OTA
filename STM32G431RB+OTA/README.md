### 项目介绍
#### 项目名称
STM32G431RB+OTA
#### 项目描述
这是一个基于STM32G431RB的OTA项目，用于实现设备的远程升级，可以在Linux和Windows环境下编译。
### 文件内容介绍
#### 注意事项
- 本项目基于 STM32CubeMX 生成的代码。
- 本项目使用了 STM32G431RB 芯片。
- 本项目使用了 makefile 进行编译，需要先安装 make 工具。    
- 本项目使用的编译器是 GNU ARM 编译器。
- 本项目使用的调试器是 J-Link。
- 本项目使用的调试工具是 Cortex-Debug。
- 本项目的SVD文件是 STM32G431.svd，文件在项目根目录下。
